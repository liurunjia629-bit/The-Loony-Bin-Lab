# 你是什么品种的废物？ · V1.1.1

原创荒诞人格网页小游戏。React + TypeScript + Vite，所有插画为源码内原创 SVG；没有账号、后端、AI API 或运行时外部资源。

## 本地启动

**最快游玩（无需安装依赖）：** 在项目目录执行 `node serve.mjs`，然后打开 `http://127.0.0.1:4173`，直接运行附带的生产构建。需要修改源码时使用下面的开发步骤。

使用 Node.js **22.18+ 或 24+**（Vite 配置使用 Node 原生 TypeScript 支持）。

```sh
npm install
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173`。

```sh
npm test
npm run build
npm run preview
```

`dist/` 已包含经过验证的生产构建。`npm run preview` 默认在 `http://127.0.0.1:4173` 运行它。不要双击 HTML：ES Modules 和浏览器保存功能需要 HTTP 服务。若受限环境中的开发依赖预打包遇到目录权限问题，可以直接使用已构建版本的 preview。

## 已实现

- 30道原创题目，每次用 Fisher–Yates 洗牌无放回抽取10题；答案锁定避免连点。
- 土豆博士五种反应状态、随机吐槽、过渡和鉴定动画，支持减少动态效果偏好。
- 12种独立 SVG 角色、完整档案、三项代表属性、评分解释。
- 900px 宽、随文案行数调整高度的竖版人格证书与双人卡，Canvas 原生 PNG 导出。手机端支持图片预览和长按保存。
- 支持文件分享的浏览器调用系统分享；其他浏览器下载分享卡。用户自行选择发送目的地。
- 好友邀请 URL 的 `?friend=编号` 参数只携带人格编号；朋友完成测试后可直接匹配。部署到可访问网址后，朋友才能打开邀请链接，localhost 仅限本机。
- 144种有序人格配对（78种不计顺序组合）保留6类关系计算逻辑，加入12种同类称号、8组特殊关系与角色专属任务。两项指数与V1.0一致。
- 图鉴、历史、连续三次同人格彩蛋、6种和12种收集里程碑；浏览器禁用存储时显示提示，不妨碍导出。
- 桌面与移动端适配；无需外部图片与字体服务，中文使用系统字体。

## 人格变异观察报告

在同一浏览器完成第二次及之后的10题鉴定，结果页会比较最近两次有效历史：不同人格显示变异报告；相同人格显示12种专属稳定文案；连续三次及以上相同则升级为“人格钉子户”，合并三连发现提示。脑洞狐狸→摸鱼树懒有专属观察。

报告可直接折叠，或点击“保存人格变异报告 ↓”导出900×1350 PNG；保留中文换行、原始角色比例和真实游戏网址。沿用 useless-lab-v1 存档，不清空历史；只有完成10题才记录一次。浏览器禁止持久存储时仍可在当前打开的游戏内累计比较，但刷新后无法保留。历史沿用原有最近100次上限，观察编号按保留历史计数。

## 品牌标识

统一品牌为「不正常人类研究所 / THE LOONY BIN LAB.」。导航采用原创手写“不”字印章，图形由SVG路径构成，不依赖字体或外部图片。

组件：`<BrandLogo size={40} mode="light" iconOnly={false}/>`；mode 支持 light/dark。图形有固定 viewBox、显式宽高及禁止flex压缩规则，独立图形具备无障碍名称。`src/brand-mark.ts` 是组件与 favicon 的共用路径源。

`public/favicon.svg` 为主图标，另提供32px ICO后备和180px Apple触屏图标。更换图形时须同步更新这三份资源。导航保留点击返回首页。

本轮浏览器验收工具初始化失败，未完成320/375/390/430px真实浏览器及Safari、微信实机验证；图形尺寸检查与生产构建不代表手机端验收。

## 评分规则

每个选项给两项属性分别加3分和1分，10题总计40分。将六维总分归一化，与12个人格预设六维向量计算余弦相似度，选最高者；平局优先图鉴编号靠前者。随机性仅用于抽题和博士台词，不参与结果计算。属性条按本次最高属性归一化，**不是**人群百分位。

不同抽题可能带来一定差异；同一题目和答案组合必然得到同一结果。这是娱乐游戏，不是经过心理学验证的测量工具。

## 代码位置

- `src/data.ts`：题库、属性权重、人格文案与模板；`src/option-replies.ts`：30 × 4条专属回复。
- `src/diagnosis.ts`：15种最高两项属性组合描述及低行动力补充规则；不改变评分。
- `src/match-stories.ts`：稳定、对称的组合文案；`src/easter-eggs.ts`：8项隐藏记录规则。
- `src/links.ts`：真实游戏入口及邀请编号解析；`src/text-layout.ts`：中文文本排版。
- `src/engine.ts`：洗牌、计分、人格匹配、好友规则、本地数据。
- `src/art.tsx`：12种 SVG 角色和博士状态。
- `src/main.tsx`：页面和游戏状态、分享邀请、交互。
- `src/export.ts`：Canvas 排版和 PNG 生成。
- `src/mutation.ts`：最近两次有效结果、12种稳定文案、6组方向性彩蛋及角色组合规则。
- `src/MutationObservation.tsx`、`src/mutation.css`：可折叠研究记录、轻量动画和减少动态效果支持。
- `src/mutation-export.ts`：按需加载的双人格报告PNG导出。
- `src/style.css`：纸感、响应式、动画。
- `tests/engine.test.ts`、`tests/v11.test.ts`、`tests/mutation.test.ts`：共20项测试，涵盖120条反馈、诊断、邀请、配对、排版、旧存档迁移和彩蛋。
- `tests/v10-regression.json`：从V1.0冻结的权重、角色向量、24组答题结果和全部144组匹配指数，防止改文案时改变原算法。

## 开发阶段

### 首页交互优化

保留原有奶油白、黑红配色、双栏排版、留白和涂鸦视觉。交互独立在 `src/Home.tsx` 与 `src/home.css`，不改计分、导出与存档规则。

- 博士眼睛最多横移3个 SVG 单位、纵移2个单位；通过单帧 requestAnimationFrame 合并鼠标移动，触屏不追视。
- 自然眨眼、悬停轻晃和点击压缩；1.5秒内连戳3／5／7次触发不同台词。
- 首页26秒无操作后出现一句提示，后续间隔45～65秒；操作重置计时，后台标签页暂停提示，离开首页清理监听与计时器。
- 开始按钮弹性压缩，博士宣布开始，约1秒进入测试；重复点击锁定，离开首页取消跳转。
- 4个人格预览支持鼠标悬停、键盘聚焦显示介绍；触摸或点击直接进入对应详情。未获得角色明确显示“尚未收录”，查看不会解锁。
- 仅青蛙偶尔待机轻动，避免所有角色同时摇摆。底部每次进入随机显示一条研究所文案。
- `prefers-reduced-motion` 下关闭动画与眼睛跟随；保留台词和短暂的状态反馈。
